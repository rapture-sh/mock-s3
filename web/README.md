# The mock-s3 console

A viewer over the JSON admin API on `:9001`. It holds no logic the server could hold
instead, and no S3 behaviour depends on it running — `--no-console` drops it entirely.

```bash
pnpm install
pnpm dev        # Vite on :5173, proxying /_admin to a mock-s3 on :9001
pnpm build      # writes dist/, which the release binary embeds
pnpm lint       # biome check
pnpm lint:fix   # biome check --write
pnpm typecheck
```

`pnpm dev` needs a mock-s3 running beside it: `cargo run -- --in-memory`.

## Layout

```
src/
  router.tsx              the route tree
  routes/                 one file per page
  components/
    layout/               sidebar, page shell
    buckets/              bucket table, create dialog, destructive actions
    objects/              object browsing and upload
    requests/             the request log
    ui/                   generated by the shadcn CLI
  hooks/use-admin.ts      fetch with polling, and a hook for writes
  lib/admin.ts            the typed admin API client
  lib/format.ts           bytes, durations, relative time
  lib/bucket-name.ts      the S3 naming rules, for instant feedback
  types/admin.ts          the shapes the admin API answers with
```

Routes are declared in `router.tsx` rather than generated from the filesystem. There are
four of them, and a generated route tree would add a build step and a committed artifact
to keep in sync for no gain at this size.

`src/components/ui` is written by the shadcn CLI and re-written by it, so Biome formats
it but does not lint it — `biome.json` turns off the one a11y rule that fires on a
primitive which has no control of its own to label.

## Conventions

Everything in the repository's `AGENTS.md` applies. For this directory in particular:

- Biome decides formatting and lint. Not ESLint, not Prettier; the preset ships with
  those and they were removed.
- Named exports. No default exports outside `vite.config.ts`.
- No `any`. Label every input.
- The admin API is the only source of data. The console never calls the S3 port: that is
  a different origin, and asking someone to configure CORS to look at their own test
  fixtures would be absurd.
- `lib/bucket-name.ts` mirrors `validate_bucket_name` in `mock-s3-core`. The server is
  authoritative and will refuse a bad name whatever the client thinks; the copy exists
  only so the dialog can explain the problem without a round trip. If the two disagree,
  the Rust one is right.

## Design

Monochrome. The palette is the shadcn neutral scale, which has zero chroma, and no accent
colour was added. The only colour on screen is an HTTP status that has gone wrong — amber
for a 4xx, red for a 5xx — so a single bad request stands out in a wall of good ones.

Inter for text, JetBrains Mono for machine strings: keys, paths, ETags, request ids.
Monospace as a label font is decoration; monospace where character alignment is the point
is not.
